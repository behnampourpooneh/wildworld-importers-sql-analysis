# wildworld-importers-sql-analysis
# 📊 Customer & Sales Analysis Project (SQL)

## 📌 Project Overview
This project analyzes customer behavior, sales performance, and product demand using SQL queries on the Wildworld Importers dataset.

The goal is to extract actionable business insights from transactional data.

---

## 🎯 Business Objectives
- Identify high-value customers
- Analyze sales performance over time
- Detect inactive customers
- Evaluate product demand
- Measure order processing efficiency

---

## 📊 Key Analyses

### 1. Customer Retention
Identified customers with no order history.

### 2. Customer Value Analysis
Calculated total revenue contribution per customer.

### 3. Product Demand Analysis
Analyzed top-selling products based on quantity.

### 4. Inventory Efficiency
Detected stock items with no sales activity.

### 5. Sales Trend Analysis
Measured monthly revenue changes.

### 6. Order Processing Time
Analyzed time difference between order and invoice.

---

## 💡 Key Insights
- Revenue is concentrated among a small group of customers.
- Some products have no demand, indicating inventory inefficiency.
- Sales show monthly fluctuations.
- Order processing time varies across customers.

---

- SQL (T-SQL)
- Window Functions
- CTEs
